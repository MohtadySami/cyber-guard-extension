# 🛡️ Cyber Guard - Real-Time Download Security Extension

**Cyber Guard** is a modern, high-performance Google Chrome extension built on **Manifest V3**. It intercepts downloaded files in real-time, computes their SHA-256 hashes, and queries the **VirusTotal v3 API** to protect users from malicious content.

---

## 🎨 Interface & Highlights
- **Dark Cyber Aesthetic:** Clean, modern, responsive UI designed for security professionals and power users.
- **Arabic Language Support:** Built-in native localization for seamless UX.
- **Secure Key Storage:** Safely isolates user API keys using `chrome.storage.local`.
- **Instant Scan Feedback:** Clear visual indicators for clean, suspicious, or dangerous files.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Extension Standard:** Chrome Extension Manifest V3
- **APIs & Tools:** VirusTotal REST API v3, Chrome Downloads API, Chrome Storage API
- **Version Control:** Git & GitHub
